Raycaster JS / WASM / WebGL frame-time benchmark

This is a browser-only companion to tools/benchmark-raycaster.mjs (which can only compare JS vs. WASM under Node -- there's no real GPU there). It builds the same shaped scene (see buildBenchmarkLevel() below, matching the Node script's level/sprites/camera sweep) and drives all three renderers -- JS, WASM, and WebGL -- back to back at the same internal resolution, in this actual browser/GPU. Open this page via npm start (not file://, so the WASM module and its relative .wasm fetch resolve correctly), then press "Run benchmark". On a Chromebook or other low-power device, run it there directly -- the whole point is real, on-device numbers, not an assumption.
